Module 03: Filesystem Architecture & Text Pipelines

⚠️
Sandbox Environment Warning
Execute all commands and scripts strictly inside an isolated Virtual Machine sandbox. Never perform bulk permission changes, system removals, or daemon restarts on unbacked host environments.

Mastering the UNIX Filesystem Hierarchy Standard, Virtual VFS (/proc, /sys), standard input/output/error streams, file discovery, and the Big 4 stream processors.

1. The Filesystem Hierarchy Standard (FHS)

The foundational principle of Linux states that "Everything is a stream of bytes (a file)." Hardware devices, network sockets, active memory state, and configuration files all reside under a unified hierarchical tree starting at /.

Filesystem Hierarchy Standard (FHS) Architecture
1. /etc (Host Configs)

System configuration files (passwd, sudoers, profile, ssh/, systemd/).

2. /var (Variable Data)

Dynamic service logs (/var/log/), container databases, and storage lib volumes (/var/lib/docker/).

3. /proc & /sys (Virtual VFS)

In-memory kernel telemetry, running process PIDs, hardware state (cpuinfo, meminfo).

4. /bin & /usr (Binaries)

Core executables (bash, grep, awk) and administrative binaries (systemctl, ip, ss).

2. Standard Streams & Pipeline Redirection

Every process launched in Linux automatically opens three integer file descriptors (FD):

Standard Streams & Pipeline Data Flow
stdin (FD 0) • Input Stream

Receives input from keyboard or pipe: command < input.txt

stdout (FD 1) • Standard Output

Standard command output: command > out.log (overwrite) or >> (append)

stderr (FD 2) • Error Output

Error logs and warnings: 2> errors.log or redirect to null: 2>/dev/null

Combined Redirection (2>&1)

Merges stdout and stderr into one stream: command > output.log 2>&1 &

3. The Big 4 Text Processors: grep, awk, sed, and cut

1. grep (Regular Expression Filtering)

# Recursive case-insensitive search skipping binary files
grep -rnI "DB_PASSWORD" /var/www/

# Exclude comment lines (#) and blank lines from configs
grep -v "^#" /etc/ssh/sshd_config | grep -v "^$"

2. awk (Column and Field Extraction)

# Print Username (col 1) and Shell (col 7) from /etc/passwd using ":" delimiter
awk -F: '{print $1 " uses shell: " $7}' /etc/passwd

# Filter processes consuming more than 5% RAM
ps aux | awk '$4 > 5.0 {print $2, $4, $11}'

3. sed (Stream Editor & Find-and-Replace)

# Replace text in-place across a configuration file
sudo sed -i 's/PermitRootLogin yes/PermitRootLogin no/g' /etc/ssh/sshd_config

# Delete blank lines from file
sed -i '/^$/d' server.conf

4. cut, sort, and uniq (Data Pipeline Aggregation)

# Extract unique client IP addresses and count hits from Nginx access logs
awk '{print $1}' /var/log/nginx/access.log | sort | uniq -c | sort -nr | head -n 10

4. Fast File Discovery with find

# Find files larger than 100MB modified in the last 24 hours
find / -type f -size +100M -mtime -1 2>/dev/null

# Audit all SUID binaries on the filesystem (security check)
find / -perm -4000 -type f -exec ls -la {} + 2>/dev/null

# Find and delete application log files older than 30 days
find /var/log/apps/ -name "*.log" -mtime +30 -delete
