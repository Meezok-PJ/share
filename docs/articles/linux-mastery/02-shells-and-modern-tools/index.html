Module 02: Shells, Prompts & Modern CLI Toolkit

Mastering Linux command interpreters, configuring startup dotfiles, supercharging terminal productivity with Starship & tmux, and replacing legacy UNIX utilities with modern Rust-powered tools.

⚠️
Shell Configuration Caution
When modifying system-wide shell scripts (/etc/profile) or user dotfiles (~/.bashrc), always keep an active SSH terminal open before logging out. Syntax errors in login scripts can prevent successful user session initialization.

1. Understanding Linux Shells

A shell is a command language interpreter that executes commands read from standard input or from a script file. The standard shells available across Linux distributions are:

  • Bash (Bourne-Again SHell): The default shell on most Linux distributions (Ubuntu, Fedora, Debian). Highly compatible with POSIX standards.
  • Zsh (Z Shell): Powerful interactive shell featuring advanced tab-completion, globbing, and extensive theme ecosystems (Oh My Zsh). Default on macOS and Kali Linux.
  • Fish (Friendly Interactive SHell): User-friendly shell with out-of-the-box syntax highlighting, autosuggestions, and clean web configuration.

2. Shell Initialization Files: Global vs. User Scope

When you start a terminal session, Linux loads configuration scripts in a strictly defined hierarchy:

Shell Startup Configuration Hierarchy
1. /etc/profile (Global Login)

System-wide environment variables, PATH defaults, and umask settings applied to ALL users upon login.

2. /etc/bashrc (Global Non-Login)

System-wide aliases and function definitions executed for every new interactive subshell.

3. ~/.bash_profile (User Login)

User-specific environment settings executed once upon initial remote SSH or console login.

4. ~/.bashrc (User Interactive)

User-specific aliases, custom functions, prompt variables (PS1), and PATH customizations.

3. The Modern Rust CLI Replacement Toolkit

Modern Linux sysadmins frequently replace 40-year-old UNIX binaries with blazing-fast, syntax-highlighted, memory-safe alternatives:

Legacy Binary Modern Tool Superpower / Key Advantage Install Command (Ubuntu/Debian)
ls eza (or lsd) Color-coded file types, Git status badges, tree view. sudo apt install eza
cat bat Syntax highlighting, line numbers, Git modifications. sudo apt install bat
grep ripgrep (rg) 10x faster recursive search, respects .gitignore. sudo apt install ripgrep
find fd-find (fd) Intuitive syntax, colorized outputs, smart case search. sudo apt install fd-find
cd zoxide (z) Fuzzy directory jumping based on usage frecency. curl -sSfL https://raw.githubusercontent.com/ajeetdsouza/zoxide/main/install.sh | sh
Ctrl + R fzf Interactive fuzzy search for files, processes, and history. sudo apt install fzf

4. Terminal Multiplexing with `tmux`

tmux (Terminal Multiplexer) allows you to run multiple persistent terminal sessions inside a single SSH connection. If your network drops, your background compiling scripts continue running uninterrupted.

# Start a new named tmux session
tmux new -s homelab_session

# Split active pane horizontally:  Ctrl + b then "
# Split active pane vertically:    Ctrl + b then %
# Switch between active panes:     Ctrl + b then Arrow Keys
# Detach from session safely:      Ctrl + b then d

# List active running tmux sessions
tmux ls

# Reattach to existing session
tmux attach -t homelab_session

5. Recommended Custom `~/.bashrc` Configuration

Add these productivity aliases to your personal ~/.bashrc:

# Modern CLI Aliases
alias ls='eza --icons --group-directories-first'
alias ll='eza -la --icons --git --group-directories-first'
alias tree='eza --tree --icons'
alias cat='batcat --paging=never'
alias grep='grep --color=auto'
alias df='df -h'
alias free='free -m'
alias ports='sudo ss -tulpn'

# Fast Reload
alias reload='source ~/.bashrc && echo "Shell config reloaded!"'
