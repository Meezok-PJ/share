Module 06: Network Sockets, SSH Transfers & Storage LVM

⚠️
Sandbox Environment Warning
Execute all commands and scripts strictly inside an isolated Virtual Machine sandbox. Never perform bulk permission changes, system removals, or daemon restarts on unbacked host environments.

Auditing listening network sockets with ss, IP routing diagnostics, encrypted SSH syncs with rsync, disk partitioning, LVM logical volume pools, Btrfs RAID, and tarball archiving.

1. Network Sockets & Diagnostic Tooling

Network Diagnostics & Socket Inspection
sudo ss -tulpn (Socket Audit)

Shows all listening TCP/UDP sockets with exact process names and PIDs.

ip route show (Gateway Routing)

Verifies default gateway routes and network interface subnets.

dig @1.1.1.1 domain (DNS Check)

Performs direct DNS lookups against upstream nameservers.

curl -Iv url (HTTP Diagnostics)

Inspects HTTP headers, TLS certificates, and response status codes.

# Check all listening ports and their managing processes
sudo ss -tulpn

# Display IP addresses assigned to network interfaces
ip -br a

# Test network path latency with ping
ping -c 4 1.1.1.1

2. Encrypted Remote File Transfers with rsync

rsync is the gold standard for incremental, compressed remote synchronization over SSH:

# Sync directory recursively with compression (-z), progress bar (-P), and archive attributes (-a)
rsync -avzP /home/meezok/project/ meezok@192.168.3.67:/mnt/storage/project/

# Sync with deletion of files removed from source (mirroring)
rsync -avzP --delete /var/www/html/ backup-server:/backups/www/

3. Storage Architecture, Partitions & LVM

Figure 1: Physical disk partitioning, mount points, and filesystem layout.
LVM Storage Layer Architecture
1. Physical Volumes (PV)

Raw physical disks or partitions (e.g. /dev/nvme0n1p3) initialized with pvcreate.

2. Volume Groups (VG)

Pools of storage combining multiple PVs into a unified storage pool with vgcreate.

3. Logical Volumes (LV)

Dynamic virtual partitions formatted with ext4/xfs and mounted to directories with lvcreate.

# Check filesystem disk utilization in human-readable units
df -h

# Check top 10 largest folders in current directory
du -sh * | sort -hr | head -n 10

# Create a timestamped gzip-compressed tarball archive
tar -czvf backup_$(date +%F).tar.gz /home/meezok/workspace/

# Extract a tarball into a specific target folder
tar -xzvf backup.tar.gz -C /opt/restored/
