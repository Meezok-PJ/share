Module 08: Self-Hosted Homelab Services & Applications

⚠️
Sandbox Environment Warning
Execute all commands and scripts strictly inside an isolated Virtual Machine sandbox. Never perform bulk permission changes, system removals, or daemon restarts on unbacked host environments.

Self-hosted homelab applications and infrastructure: Fedora workstation host tuning, deploying CasaOS, running containerized Code-Server, Pi-hole network DNS ad-blocking, NetBird mesh VPN, and Ollama local AI hosting.

1. Fedora Host Post-Install & Development Tuning

# 1. Enable fastest mirrors and parallel downloads in DNF
sudo tee -a /etc/dnf/dnf.conf << 'EOF'
fastestmirror=True
max_parallel_downloads=10
defaultyes=True
EOF

# 2. Update all system packages
sudo dnf upgrade --refresh -y

# 3. Install Docker Engine on Fedora
sudo dnf install -y dnf-plugins-core
sudo dnf-3 config-manager --add-repo https://download.docker.com/linux/fedora/docker-ce.repo
sudo dnf install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo systemctl enable --now docker
sudo usermod -aG docker $USER

2. Deploying CasaOS & Containerized Code-Server

CasaOS is a lightweight, elegant home cloud management system that turns any headless Ubuntu/Debian server into an intuitive app dashboard:

# Install CasaOS with a single curl script
curl -fsSL https://get.casaos.io | sudo bash

Once installed, navigate to http://<VM-IP-ADDRESS> in your browser to access the CasaOS dashboard.

Figure 1: CasaOS web management dashboard displaying system health, CPU/RAM meters, and installed containers.

Deploying Code-Server (VS Code in the Browser)

From the CasaOS App Store (or via Docker Compose), deploy linuxserver/code-server to run a full Visual Studio Code IDE accessible from any web browser on your network:

services:
  code-server:
    image: lscr.io/linuxserver/code-server:latest
    container_name: code-server
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=UTC
      - PASSWORD=mysecretpassword
    volumes:
      - /home/meezok/workspace:/config/workspace
    ports:
      - 8443:8443
    restart: unless-stopped

3. Network-Wide Ad-Blocking with Pi-hole DNS

services:
  pihole:
    container_name: pihole
    image: pihole/pihole:latest
    ports:
      - "53:53/tcp"
      - "53:53/udp"
      - "8088:80/tcp"
    environment:
      TZ: 'UTC'
      WEBPASSWORD: 'adminpassword'
    volumes:
      - './etc-pihole:/etc/pihole'
      - './etc-dnsmasq.d:/etc/dnsmasq.d'
    restart: unless-stopped

4. Local AI Model Hosting with Ollama

# Install Ollama on Linux
curl -fsSL https://ollama.com/install.sh | sh

# Pull and run local vision & reasoning models
ollama run qwen3-vl:8b
ollama run deepseek-r1:8b
