Module 07: Docker Container Engineering & Compose Stacks

⚠️
Sandbox Environment Warning
Execute all commands and scripts strictly inside an isolated Virtual Machine sandbox. Never perform bulk permission changes, system removals, or daemon restarts on unbacked host environments.

Deep-dive into Docker container architecture vs VMs, CLI lifecycle commands, multi-stage production Dockerfiles, volume persistence, bridge networking, and multi-service docker-compose stacks.

1. Docker Container Architecture vs. Virtual Machines

Docker Engine Architecture Mind Map
1. Engine Architecture

dockerd daemon, REST API client, containerd OCI runtime, Linux cgroups & namespaces.

2. Image Building

Multi-stage Dockerfile, build caching, minimal base images (Alpine/Distroless), non-root users.

3. Lifecycle Operations

Interactive: run -it --rm, in-container: exec -it sh, health: stats, graceful: stop → rm.

4. Volume Persistence

Bind mounts (./src:/app:ro), named volumes (/var/lib/docker), database state isolation.

5. Networking Modes

Default bridge, direct host bypass, custom isolated subnets, port mapping (-p 8080:80).

6. Compose Stacks

Multi-service docker-compose.yml, dependency ordering (depends_on), environment secrets (.env).

2. Essential Docker CLI Commands

# Run an ephemeral interactive Ubuntu container
docker run -it --rm ubuntu:24.04 bash

# Run a detached Nginx web server with host port publishing
docker run -d --name my_webserver -p 8080:80 --restart unless-stopped nginx:alpine

# Execute an interactive shell inside a running container
docker exec -it my_webserver sh

# Inspect live CPU and Memory usage statistics across containers
docker stats --no-stream

# View live container log stream
docker logs -f --tail=100 my_webserver

3. Multi-Stage Production Dockerfile

# Stage 1: Build stage
FROM golang:1.24-alpine AS builder
WORKDIR /app
COPY go.mod go.sum ./
RUN go mod download
COPY . .
RUN CGO_ENABLED=0 GOOS=linux go build -o /app/server .

# Stage 2: Minimal runtime stage
FROM alpine:3.20
WORKDIR /app
RUN adduser -D -u 1000 appuser
COPY --from=builder /app/server /app/server
USER appuser
EXPOSE 8080
ENTRYPOINT ["/app/server"]

4. Multi-Service Orchestration (docker-compose.yml)

services:
  web:
    image: node:20-alpine
    container_name: web_app
    restart: unless-stopped
    working_dir: /app
    volumes:
      - ./src:/app:ro
    ports:
      - "3000:3000"
    environment:
      - DB_HOST=db
      - DB_USER=appuser
      - DB_PASSWORD=secretpassword
    depends_on:
      - db
    networks:
      - app_network

  db:
    image: postgres:16-alpine
    container_name: db_postgres
    restart: unless-stopped
    environment:
      POSTGRES_USER: appuser
      POSTGRES_PASSWORD: secretpassword
      POSTGRES_DB: appdb
    volumes:
      - postgres_data:/var/lib/postgresql/data
    networks:
      - app_network

volumes:
  postgres_data:

networks:
  app_network:
    driver: bridge
# Deploy entire stack in background
docker compose up -d

# Verify running services
docker compose ps

# Stop stack
docker compose down
